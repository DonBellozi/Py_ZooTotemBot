# Moscow Zoo Totem Bot

Telegram-бот-викторина для подбора тотемного животного Московского зоопарка и популяризации программы опеки «Клуб друзей зоопарка».

## Что умеет бот

- запускается по команде `/start`;
- показывает приветственное сообщение с логотипом;
- использует случайные приветственные фразы, чтобы стартовое сообщение не выглядело однообразно;
- проводит интерактивную викторину с inline-кнопками;
- считает результат по системе баллов;
- показывает итоговое животное;
- отправляет изображение животного, если файл добавлен в папку `images`;
- рассказывает о программе опеки «Клуб друзей зоопарка»;
- дает ссылку на официальную страницу программы опеки;
- позволяет связаться с сотрудником;
- отправляет администратору результат пользователя при запросе связи;
- позволяет поделиться ссылкой на викторину;
- собирает отзывы пользователей;
- позволяет администратору посмотреть последние отзывы командой `/feedbacks`;
- содержит команду `/animal_fact` и кнопку «Факт о животных»;
- позволяет пройти викторину заново.

## Дополнительные возможности

В проект добавлены функции, которые делают бота более живым и удобным:

- случайная приветственная фраза при запуске;
- приветственное изображение `logo.jpeg`;
- кнопка и команда для получения случайного факта о животном;
- сохранение отзывов пользователей в SQLite;
- просмотр последних отзывов администратором через команду `/feedbacks`;
- защита административной команды проверкой `ADMIN_ID`.

## Установка

1. Клонировать репозиторий или распаковать архив.

2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать виртуальное окружение.

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

4. Установить зависимости:

```bash
pip install -r requirements.txt
```

5. Создать файл `.env` на основе `.env.example`:

```bash
copy .env.example .env
```

Для Linux/macOS:

```bash
cp .env.example .env
```

6. Заполнить `.env`:

```env
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_ID=ваш_telegram_id
BOT_USERNAME=username_бота_без_@
```

7. Добавить изображения животных в папку `images`. Присутствуют в репозитории на Github.

Ожидаемые имена файлов:

```text
logo.jpeg
manul.jpeg
meerkat.jpeg
raccoon.jpeg
flamingo.jpeg
elephant.jpeg
alpaca.jpeg
sea_lion.jpeg
sloth.jpeg
orangutan.jpeg
```

8. Запустить бота:

```bash
python bot.py
```

## Как работает викторина

Вопросы находятся в файле:

```text
data/questions.json
```

Каждый вариант ответа начисляет баллы одному или нескольким животным.

Пример:

```json
{
  "text": "🤫 Сначала наблюдаю",
  "scores": {
    "manul": 2,
    "orangutan": 1
  }
}
```

После последнего вопроса бот выбирает животное с максимальным количеством баллов.

## Как добавить новое животное

1. Добавить карточку животного в `data/animals.json`.
2. Добавить изображение в `images`.
3. Добавить баллы для этого животного в варианты ответов в `data/questions.json`.

## Масштабируемость

Проект спроектирован с учетом возможного роста количества пользователей:

- используется асинхронный фреймворк aiogram 3;
- состояние викторины хранится отдельно для каждого пользователя по его Telegram ID;
- вопросы и животные вынесены в JSON-файлы;
- логика викторины, клавиатуры, загрузка данных и хранение результатов разделены по модулям;
- результаты и отзывы сохраняются в SQLite;
- изображения хранятся локально и не загружаются из внешних источников во время прохождения викторины.

При необходимости SQLite можно заменить на PostgreSQL, не меняя основную логику викторины.

## Конфиденциальность

Бот не запрашивает лишние персональные данные. Для работы используются только данные, которые Telegram передает боту автоматически:

- Telegram ID;
- имя пользователя;
- username, если он указан;
- результат прохождения викторины;
- текст отзыва, если пользователь решил его оставить.

Отзывы и результаты сохраняются локально в SQLite. Административный доступ к просмотру отзывов ограничен значением `ADMIN_ID`.

## Креативность и уникальность

Проект выполнен не как обычный тест, а как интерактивная викторина «Тотемное животное Московского зоопарка». Пользователь получает персональный результат на основе ответов, изображение животного и короткое описание характера.

Для каждого животного подготовлен отдельный образ: манул – спокойный наблюдатель, сурикат – командный игрок, енот-полоскун – любопытный исследователь, фламинго – яркий эстет, слон – надежная опора, альпака – символ уюта, сивуч – харизматичный любитель отдыха, ленивец – мастер энергосбережения, орангутан – наблюдательный мыслитель.

Бот использует логотип, изображения животных, дружелюбные формулировки, случайные приветственные фразы, факты о животных, кнопки для повторного прохождения, обратной связи и перехода к программе опеки.
